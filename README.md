# Chanda — My Moon

A responsive, GitHub Pages-ready personal website for Chanda.

## What is included
- Responsive layout for phone, tablet, laptop and desktop.
- Home page with a new photo collage using the strongest smiling/outdoor photos from the supplied project.
- Large Memories page with captions, category filters and a full-screen photo viewer.
- The current letter text from the supplied code has been preserved.
- All 23 photo assets extracted from the supplied HTML are included in `assets/`.
- `videos/` is ready for the videos from your Google Drive folder.

## Run locally
Just double-click `index.html`, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Go to Settings → Pages.
4. Select the main branch and `/root` (or the repository root).
5. GitHub will give you a public link.

## Adding more photos
Put new JPG/PNG files in `assets/` and add an entry to `galleryData` in `script.js`.

## Adding videos
Put MP4 files in `videos/`. Video cards can be added to the same Memories grid later.
